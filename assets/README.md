## Tips
- Export CAD at ~200–300 DPI for print; keep dark (#07080C / #07090E) backgrounds or transparency.
- Bracketed values in the HTML like `[4.8]` and `[EDITABLE: …]` are meant to be rewritten.
- After swapping, refresh `http://localhost:3851` and run **Export PDF**.
